UNDANGAN DIGITAL KAHFI & RIRIN — VERSI REKONSTRUKSI REFERENSI

Isi folder:
- index.html : struktur/isi undangan
- style.css  : desain responsif, warna navy + abu-abu + gold
- script.js  : navigasi, transisi, musik, bagikan undangan, form ucapan
- assets/    : foto demo sementara

CARA PREVIEW
1. Ekstrak ZIP.
2. Buka index.html melalui browser. Untuk hasil paling konsisten, gunakan VS Code + Live Server atau unggah folder ke GitHub Pages setelah diperiksa.
3. Jangan unggah/publikasikan sebelum Anda menyetujui hasilnya.

PENTING
- Foto dalam assets saat ini adalah foto demo dari versi sebelumnya, bukan foto pribadi Kahfi & Ririn. Ganti dengan foto pasangan sendiri; nama file yang dipakai di HTML dapat dipertahankan atau ubah path-nya.
- Lokasi acara belum diisi karena belum ada alamat final.
- Musik tidak disertakan. Jika ingin musik, masukkan file MP3 bernama assets/music.mp3.
- Form ucapan membuka WhatsApp dengan pesan yang sudah disiapkan; nomor WhatsApp penerima belum dikonfigurasi.

UPDATE VIDEO, MUSIC, DAN HADIAH
- Unggah video global ke folder images dengan nama: video-background.mp4
- Unggah musik ke folder images dengan nama: music.mp3
- Video global berjalan diam di belakang website; musik mulai dicoba ketika tombol Buka Undangan ditekan atau ketika pengunjung melewati cover. Browser HP dapat mensyaratkan interaksi pengguna.
- Halaman Hadiah kini terpisah setelah Ucapan dan sebelum Penutup.
- Di index.html, ganti ISI_NOMOR_REKENING_BCA, ISI_NAMA_PEMILIK_BCA, ISI_NOMOR_DANA, dan ISI_NAMA_PEMILIK_DANA dengan data asli.
- Untuk memperlihatkan video melalui background halaman, tambahkan class video-transparent atau video-light pada section terkait, tanpa menghapus class lama.
